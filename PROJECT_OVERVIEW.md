# PROJECT_OVERVIEW.md

## 1. EXECUTIVE SUMMARY & MISSION

### What is the Product?
An autonomous, enterprise-grade Airline Flight Management & Customer Experience Platform.

### Core Architecture
This platform utilizes a dual-writer system pairing a high-concurrency FastAPI synchronous write engine with n8n Cloud automations, Supabase PostgreSQL with pgvector, and Google Gemini 2.0 Flash for AI integration.

### The Core Problem It Solves
- **Eliminates Seat Overselling:** Prevents race conditions during high-traffic checkouts using robust row-level locks.
- **Automates Waitlist Promotions:** Automatically manages standby and waitlist promotions as seats become available.
- **Prevents Bot Fraud Bursts:** Features real-time fraud detection to block malicious booking attempts.
- **Provides Zero-Hallucination AI Support:** Delivers highly accurate customer service powered by AI (RAG) with a mandatory human approval gate for guaranteed quality assurance.

## 2. USER PERSONAS & CORE USER JOURNEYS

### Persona 1: The Passenger / Traveler
- **Search & Price Lock:** Searches flights by route and date, views live seat availability, and locks ticket prices for a guaranteed 15 minutes.
- **Seat Selection:** Interacts with a visual airplane seat map to select physical seats across First, Business, and Economy classes.
- **Checkout & Ticket:** Checks out with guaranteed idempotency and receives an instant 6-character PNR ticket.
- **Booking Management:** Cancels tickets with dynamic, fare-branching refund calculations (Basic Economy $0, Flexible 90%, Premium First 100%) or joins standby queues for fully booked flights.
- **AI Support:** Engages with an AI support chat to ask policy-related questions such as baggage rules and refund conditions.

### Persona 2: The Customer Support / Ops Agent
- **Human Approval Gate:** Reviews, verifies, and approves or rejects AI-drafted policy responses generated by Google Gemini before they are dispatched to passengers.
- **Queue Management:** Monitors passenger waitlist promotions and standby queues.

### Persona 3: The Airline Super Admin
- **Flight Scheduling & Capacity:** Creates flights, defines seat class capacities, and shifts flight schedules.
- **Disruption Simulation:** Simulates major schedule disruptions (e.g., a >180-minute time shift automatically triggers a 100% refund policy override).
- **Security & Governance:** Monitors real-time bot fraud spikes and inspects the immutable audit log for all system activities.

## 3. THE 4 ESSENTIAL FRONTEND SCREENS / TABS (HACKATHON MVP)

*Note: For exact technical endpoints and data models supporting these UI components, please refer to the `FRONTEND_API_GUIDE.md` document.*

### Screen 1: Flight Search & Interactive Booking Portal
- **Route Picker:** Inputs for Origin, Destination, and Date.
- **Flight Card:** Displays class pricing, live seat counts, and a prominent 15-minute price lock countdown timer.
- **Visual Airplane Seat Map:** A modal presenting a grid of seats (e.g., 1A to 30F), dynamically colored by status (AVAILABLE, HELD, BOOKED).
- **Checkout Drawer:** Captures passenger details and returns the confirmed PNR ticket upon successful idempotency-guaranteed booking.

### Screen 2: Manage Booking & Waitlist Hub
- **PNR Lookup:** A search bar to retrieve existing tickets by their 6-character PNR.
- **Ticket Detail Card:** Displays passenger information, selected fare class, and seat number.
- **Cancellation Modal:** Illustrates the fare-branching refund breakdown (e.g., $0 vs 90% vs 100%) before confirming the cancellation.
- **Waitlist Tracker:** Shows current queue position, priority score, and displays a dynamic "Claim Seat" button when the user is promoted.

### Screen 3: AI Policy Assistant (Google Gemini RAG)
- **Interactive Chat:** A sleek customer service interface for passengers to ask refund or baggage policy questions.
- **Ops Agent View Toggle:** A mode that switches the UI to display the AI-generated draft response, complete with actionable [Approve & Send] and [Reject] buttons for the Ops Agent.

### Screen 4: Admin Operations & Governance Console
- **Flight Creation Form:** Allows admins to create new flights with built-in aircraft capacity validation.
- **Schedule Shift Simulator:** A tool to simulate delays, featuring a prominent banner when a >180-minute time change is triggered.
- **Fraud Detection Alert Panel:** A real-time dashboard displaying flagged bot IPs and fraud alerts.
- **Audit Log Table:** A paginated table showing admin IDs, timestamps, and JSON deltas of all operational actions.

## 4. DESIGN SYSTEM & USER EXPERIENCE GUIDELINES

### Aesthetic
- **Theme:** Modern, high-end aviation theme.
- **Color Palette:**
  - Backgrounds: Deep navy blue/slate (`#0f172a`)
  - Surfaces: Crisp white card surfaces
  - Accents: Airline blue (`#0284c7`) and emerald green (`#10b981`) for success/active states.

### Components
- **Framework:** Clean Tailwind CSS.
- **Iconography:** Lucide icons (Airplane, Clock, ShieldCheck, Ticket, Users) for a consistent and professional look.

### Micro-Interactions
- **Countdown Badges:** Real-time visual timers for 15-minute price locks.
- **Seat Status Badges:** Instantly updating visual indicators for seat holds.
- **Toast Notifications:** Clear, non-intrusive feedback upon successful or failed actions (e.g., booking confirmed, waitlist joined, seat claimed).
