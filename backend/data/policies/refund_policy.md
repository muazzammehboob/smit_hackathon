# Refund Policy

## Basic Economy (BASIC_ECONOMY)
Tickets in the Basic Economy fare class are strictly non-refundable. Cancellations will result in a $0 refund. No exceptions are made unless covered by our 180-minute airline disruption automatic full-refund waiver.

## Flexible (FLEXIBLE)
Tickets in the Flexible fare class are eligible for a 90% refund of the base fare if cancelled. A 10% processing fee is deducted from the total refund amount. Cancellations must be made prior to the scheduled departure time.

## Premium First (PREMIUM_FIRST)
Tickets in the Premium First fare class are fully refundable. Cancellations will result in a 100% refund of the ticket price with no penalty fees, provided the cancellation is made prior to the scheduled departure.
